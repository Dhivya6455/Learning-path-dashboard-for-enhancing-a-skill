# Learning Path Dashboard for Enhancing a Skill

A personalized learning platform that helps users identify their skill level through an assessment quiz, analyzes weak areas, recommends a structured learning path with video-based course content, tracks progress, and conducts a final assessment before issuing a certificate.

## Features

* User registration and login
* Skill selection and assessment quiz
* Automatic analysis of weak areas
* Personalized learning path recommendation
* Course content with video resources
* Progress tracking dashboard
* Final assessment
* Certificate generation for scores above 75%
* Responsive web interface

## How to Run

### Prerequisites

* Java 17 or above
* Maven
* VS Code or IntelliJ IDEA

### Steps

1. Clone the repository
   git clone https://github.com/Dhivya6455/Learning-path-dashboard-for-enhancing-a-skill.git

2. Navigate to the project directory
   cd Learning-path-dashboard-for-enhancing-a-skill

3. Run the Spring Boot application
   mvn spring-boot:run

4. Open the application in your browser
   https://profound-choux-374a11.netlify.app/

## Workflow

1. Register or log in
2. Select a skill
3. Take the assessment quiz
4. View skill analysis and weak areas
5. Follow the recommended learning path
6. Complete course modules and videos
7. Take the final assessment
8. Receive a certificate if the score is 75% or higher
